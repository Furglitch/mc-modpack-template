# The `server/` Folder

This template includes a `server/` folder that contains files necessary for running a dedicated Minecraft server for your modpack. This includes startup scripts and Java args.

These are the files that will be included in the server .zip file generated by the `Build Modpack` GitHub Actions workflow.

## Default Files
By default, the `server/` folder contains the following files:
- *`start-server.sh`* - A bash script for starting the server on Linux/Mac systems
- *`start-server.bat`* - A batch script for starting the server on Windows systems
- *`java-args.txt`* - A text file containing default Java arguments for running the server
  - Default args include:
    - *`-Xms2G`* - Sets the initial/minimum memory allocation to 2GB
    - *`-Xmx8G`* - Sets the maximum memory allocation to 8GB
    - *`-XX:+UseG1GC`* - Enables the G1 Garbage Collector
    - *`-XX:+ParallelRefProcEnabled`* - Enables parallel reference processing (improves Garbage Collection performance)
    - *`-XX:MaxGCPauseMillis=200`* - Sets a target for maximum GC pause time (in milliseconds)

**Note:** The startup scripts have a `(MODLOADER)_VERSION` placeholder in them, where `(MODLOADER)` is the modloader used in that branch (e.g., NEOFORGE_VERSION). This will be automatically replaced with the correct version number when being built by the GitHub Actions workflow. You do not need to change this manually.

## Adding Files
You can add additional files to the `server/` folder as needed for your modpack's server setup. These files will be included in the server .zip file when built.

### Files that can/should be added
- *`server-icon.png`* - Must be a 64x64 PNG image. This icon will be displayed in the server list of Minecraft clients connecting to the server.
- *`server.properties`* - The configuration file for the Minecraft server. You can customize various server settings here, such as game mode, difficulty, and more. This will be automatically generated with default values if not provided. More information can be found on the [Minecraft Wiki](https://minecraft.wiki/w/Server.properties).

### Files that aren't recommended to be added
- *`banned-players.json`* - This file contains the list of banned players. It's recommended to let server operators manage this themselves.
- *`ops.json`* - This file contains the list of server operators. It's recommended to let server operators manage this themselves.
- *`whitelist.json`* - This file contains the list of whitelisted players. It's recommended to let server operators manage this themselves.

### Files you should NEVER add
- *`libraries/`* folder - The server's libraries will be automatically downloaded when the server is first run. Including this folder will bloat the server .zip file unnecessarily and is a violation of Minecraft's distribution policies.
- *`logs/`* folder - This folder is generated by the server to store log files. Including it is unnecessary and may lead to confusion.
- *`world/`* folder - The server's world data will be generated when the server is first run. Including it would bloat the server .zip file and is not recommended, unless your modpack specifically requires a pre-generated world, ala [Blightfall](https://www.technicpack.net/modpack/blightfall.592618).
- *`banned-ips.json`* - This file contains the list of banned IP addresses. On top of being recommended to let server operators manage this themselves, it can also contain sensitive information.
- *`eula.txt`* - Including this is a violation of the Minecraft EULA. This file will be automatically generated when the server is first run and needs to be manually accepted by the server operator.
- *Files already in the `packwiz/` folder* - These files are already included in the server .zip file when built, so including them again in the `server/` folder would be redundant and may cause conflicts if versions or filenames differ.

Any files not mentioned above should be evaluated on a case-by-case basis to determine if they are necessary for the server setup and do not violate any distribution policies.
