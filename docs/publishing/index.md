# Publishing the Modpack

After setting up and testing your modpack, you're ready to publish it to your desired platform.

It's recommended to use the artifacts generated by the GitHub Actions workflow named `Build Modpack` for publishing, as these artifacts are built in a clean environment and ensure that all dependencies are correctly included.

## A note on Action artifacts
As mentioned in [Testing the Modpack](./testing/#a-note-on-action-artifacts), the actual files needed for publishing client packs are contained within the generated .zip artifacts, so be sure to extract them before proceeding with the publishing steps.

## Publishing to CurseForge
1. Download the CLIENT artifact from the `Build Modpack` workflow.
   This file will be named `<Modpack Name> <Version> - CurseForge Client.zip`.
2. Extract the .zip file to obtain the modpack's `.zip` file.
   This file will be named `<Modpack Name>-<Version>-CLIENT-CURSEFORGE.zip`<br><br>

3. Log in to your [CurseForge](https://www.curseforge.com/) account.
4. Navigate to the [Projects dashboard](https://authors.curseforge.com/#/projects) and edit/create your modpack project.
   Details on creating a new project can be found on [CurseForge Support](https://support.curseforge.com/support/solutions/articles/9000196904-creating-a-custom-profile-modpack).
5. In the Files tab, click on "Add File".
6. Upload the extracted modpack `.zip` file.
7. Fill in the required details such as Display Name, Modloader, Minecraft version, Release Type, and Changelog.
   - For Display name, you should include the modpack version, at the minimum.
   - It is not necessary to fill out the 'Related Projects (Dependencies)' section, as this is just a list of mods included in the modpack and will be automatically handled by CurseForge.
8. Click "Add File" to publish your modpack.

### Publishing a Server Pack
1. Download the SERVER artifact from the `Build Modpack` workflow.
   This file will be named `<Modpack Name>-<Version>-SERVER.zip`.
3. In the Files tab of your modpack project, click on the arrow next to the name of the client pack file you previously uploaded.
4. Click on "Add Additional File".
5. Upload the server pack `.zip` file.
6. Fill in the Display Name, Release Type, and Additional File Info.
   - You should match the Display Name of the client pack, and add 'Server' or 'Server Pack' to the end, or something to help users identify it.
   - Additional File Info should be set to 'Server Pack' by default, but may need to be selected from the dropdown.
   - The changelog can be left blank for the server pack, though if you haven't detailed changes that affect the server (such as changing the server icon) in the client pack changelog, you may want to add them here.
7. Click "Add File" to publish your server pack.

**Note:** The server pack includes the fully downloaded mods, so the file size may be significantly larger than the client pack. This is generally allowed on CurseForge, but be aware of any file size limits that may apply.

## Publishing to Modrinth
1. Download the CLIENT artifact from the `Build Modpack` workflow.
   This file will be named `<Modpack Name> <Version> - Modrinth Client.zip`.
2. Extract the .zip file to obtain the modpack's `.mrpack` file.
   This file will be named `<Modpack Name>-<Version>-CLIENT-MODRINTH.mrpack`<br><br>
3. Log in to your [Modrinth](https://modrinth.com/) account.
4. Navigate to the [Projects dashboard](https://modrinth.com/dashboard/projects) and edit/create your modpack project.
5. Navigate to the Versions tab and click on "Create Version".
6. Upload the extracted modpack `.mrpack` file. Fill in all the required details.
7. Click "Create Version" to publish your modpack.

### Publishing a Server Pack
1. Download the SERVER artifact from the `Build Modpack` workflow.
   This file will be named `<Modpack Name> <Version> - Modrinth Server.zip`.
2. Extract the .zip file to obtain the modpack's `.mrpack` file.
   This file will be named `<Modpack Name>-<Version>-SERVER-MODRINTH.mrpack`<br><br>
2. Navigate to the Versions tab of your modpack project and open the version you previously created for the client pack.
3. Click on 'Edit files'.
4. Upload the server pack `.zip` file. Fill in the required details.
5. Click "Save files" to publish your server pack.
